Aktifkan image storage

UI dan alur upload sudah siap, tetapi storage perlu dihubungkan ke Cloudinary agar gambar punya URL permanen. Ini hanya setup untuk pemilik website, bukan akun untuk pengunjung.

  1. Buat cloud di Cloudinary.
  2. Buat upload preset baru dengan Signing Mode: Unsigned.
  3. Batasi preset ke format gambar yang dibutuhkan dan ukuran maksimum 10 MB.
  4. Masukkan nilai di config.js, commit ke GitHub, lalu deploy ulang.
window.UPLOADER_CONFIG = { cloudName: "nama-cloud", uploadPreset: "nama-preset" };

Jangan masukkan API Secret ke frontend. Gunakan preset khusus dengan batasan upload.
